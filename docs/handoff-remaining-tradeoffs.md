# Handoff: Remaining Trade-offs

**Date:** 2026-05-31
**PR #70:** https://github.com/knirski/subsloth/pull/70
**Branch:** `feat/all-targets-room-datastore`
**State:** OPEN (unmerged), CI should re-run after push

## What This PR Achieves

Moves `wasmJs` target into the base `subsloth.kmp.library` convention so all KMP
modules compile for JVM + iOS + wasmJs. Provides proper platform implementations
using standard browser APIs. See PR description for full changeset.

### Trade-offs Resolved in This PR

| Gap | Solution |
|---|---|
| Navigation3 on desktop | `SavedStateConfiguration` + `androidx.savedstate:savedstate:1.5.0` |
| Navigation3 on web (wasmJs) | `savedstate:1.5.0` + `savedstate-compose` (wasm support since 1.3.2) |
| Room 3.0 on wasmJs | `sqlite-web` + `WebWorkerSQLiteDriver` via `kotlinx-browser` |
| DataStore on wasmJs | `PreferenceDataStoreFactory.createWithPath` |
| HMAC-SHA256 on wasmJs | Web Crypto API `crypto.subtle` via `@JsFun` |
| CredentialStore on wasmJs | `kotlinx.browser.localStorage` |
| NFC normalization on wasmJs | JS `String.prototype.normalize('NFC')` via `@JsFun` |

## Remaining Trade-offs (Not Addressed)

### 1. `androidTarget()` in KMP convention (`docs/known-gaps.md` #1)

**Why deferred:** Pure build-system refactor. The current approach (Android AGP
consumes KMP modules as JVM bytecode) works. Adding `androidTarget()` would
enable `androidMain` source sets but requires migrating `:core:media` and
`:core:datasource-ktor` (which depend on Android-only Media3).

**What it enables:** `WorkManager` in `:feature:library` (currently removed),
Android-specific `expect`/`actual` in shared modules.

### 2. Compose Hot Reload (`docs/known-gaps.md` #2)

**Why deferred:** The `org.jetbrains.compose.hot-reload` plugin wasn't available
at version `1.12.0-alpha01`. Needs investigation of available versions.

### 3. SQLite web worker bundling (`docs/known-gaps.md` — implicit)

**Status:** `:webApp` doesn't bundle the `sqlite-wasm-worker` NPM package yet.
The database wasm builder creates `Worker("sqlite-wasm-worker/worker.js")` which
needs to be available in the webpack bundle. See `sidekick` project's approach:
`npm("sqlite-wasm-worker", ...)` in `:webApp/build.gradle.kts`.

### 4. `local.properties` hardcoded Nix path (`docs/known-gaps.md` #8)

**Status:** Points to a specific Nix store hash. Breaks on `nix-collect-garbage`.
Should be auto-generated by the Nix flake or `direnv`.

### 5. `WebWorkerSQLiteDriver` nullable bug

**Known issue:** `sqlite-web:2.7.0-alpha05` has a bug where `isNull` caches
the column type from the first row only. If row 0 has a non-null Int and row 1
has NULL in the same column, Room's reader NPEs. This is a Room/SQLite alpha
issue documented in `linhvnguyen9/room3-sqlite-web-nullable-npe-repro`.

### 6. `ViewModelInjection` detekt suppressions

**Files:** `desktopApp/DesktopNavHost.kt`, `webApp/WebNavHost.kt`
**Reason:** The `PlayerContent` helper uses `viewModel(key = contentId)` which
triggers detekt's `ViewModelInjection` rule. The suppression is correct because
we intentionally derive the ViewModel key from composable state. No cleaner
way exists with the current Navigation3 + KMP lifecycle API.
