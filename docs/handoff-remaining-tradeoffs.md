## What This PR Achieves

Moves `wasmJs` target into the base `subsloth.kmp.library` convention so all KMP
modules compile for JVM + iOS + wasmJs. Provides proper platform implementations
using standard browser APIs. See PR description for full changeset.

## Remaining Trade-offs (Not Addressed)

### 1. DataStore on wasmJs — not persisted (issue #71)

**Status:** `PreferenceDataStoreFactory.createWithPath` compiles, but Okio 3.17
doesn't provide `FileSystem.SYSTEM` for wasmJs (browsers have no synchronous
filesystem API). At runtime, the DataStore will throw when attempting file I/O.
Preferences are held in memory for the session and lost on page reload.

**Issue:** https://github.com/knirski/subsloth/issues/71

**Possible solutions:**
- Upgrade Okio when a version ships `FileSystem.SYSTEM` for wasmJs
- Switch to `russhwolf/multiplatform-settings` (has localStorage support for web)
- DataStore making `PreferencesSerializer` public

### 2. `androidTarget()` in KMP convention (`docs/known-gaps.md` #1)

**Status:** Pure build-system refactor. Current approach (Android AGP consumes KMP
modules as JVM bytecode) works. Adding `androidTarget()` would enable `androidMain`
source sets but requires migrating `:core:media` and `:core:datasource-ktor`
(which depend on Android-only Media3). Enables `WorkManager` in `:feature:library`.

### 3. Compose Hot Reload (`docs/known-gaps.md` #2)

**Status:** Plugin not available at version `1.12.0-alpha01`. Needs investigation.

### 4. SQLite web worker bundling

**Status:** `:webApp` doesn't bundle the `sqlite-wasm-worker` NPM package.
The database wasm builder creates `Worker("sqlite-wasm-worker/worker.js")` which
needs to be available in the webpack bundle.

### 5. `local.properties` hardcoded Nix path (`docs/known-gaps.md` #8)

**Status:** Points to a specific Nix store hash. Breaks on `nix-collect-garbage`.
Should be auto-generated by flake or `direnv`.

### 6. `WebWorkerSQLiteDriver` nullable bug

**Status:** `sqlite-web:2.7.0-alpha05` has a bug where `isNull` caches the column
type from the first row only. Documented in `linhvnguyen9/room3-sqlite-web-nullable-npe-repro`.

### 7. `ViewModelInjection` detekt suppressions

**Files:** `desktopApp/DesktopNavHost.kt`, `webApp/WebNavHost.kt`
**Status:** Correct `@Suppress` usage — necessary because `viewModel(key = contentId)`
derives the ViewModel key from composable state. No cleaner approach exists with
current Navigation3 + KMP lifecycle API.

### 8. Web Crypto `@JsFun` Promise interop

**Files:** `core/preferences/src/wasmJsMain/AccountProfileStore.wasm.kt`
**Status:** `webCryptoHmacHex` JS function returns a Promise (because
`crypto.subtle.sign` is async), but Kotlin/Wasm `@JsFun` returns the Promise
object synchronously. Proper `Promise.await()` interop for wasmJs needs
`kotlinx.coroutines` support that isn't available for wasmJs. At runtime, the
function receives a Promise object instead of the hex string. Functionality
degrades gracefully — profile key derivation will fail on wasmJs.
