# Changelog

## 0.1.0 (2026-05-20)

Initial SubSloth release — Android streaming client for language learning through video.

- Dual-subtitle language learning while watching movies and series
- Catalog browsing with search, filters, and sort
- Video playback with quality selection, subtitles, and resume
- Offline downloads with queue management
- Login, library, settings, and diagnostics
- TV-focused UI with D-pad navigation and accessibility
- Nix flake development environment with pinned Android SDK 36
